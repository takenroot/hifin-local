# HiFin 功能清单（本地可复刻版）

基于对 `https://app.hifin.ai` 前端界面的逐项探索整理。以下功能均可在**去除云端同步/AI 云端调用**的前提下，用本地状态 + IndexedDB 实现。

---

## 一、全局结构与导航

### 1.1 布局
- 左侧固定侧边栏（约 200px），顶部/底部有功能入口
- 右侧主内容区，顶部有页面标题和快捷操作
- 整体浅色主题，支持暗黑模式切换

### 1.2 侧边栏菜单
- 顶部：空间切换（默认空间 / 全部空间 / 添加空间）
- 搜索框：⌘K 命令面板入口
- 设置按钮（齿轮图标）
- 主导航：
  - 看板（/home）
  - 账户（/account/list）
  - 交易（/transaction）
  - 预算（占位，当前点击跳回看板）
  - 目标（/goal/list）
  - 报表（/report/list）
  - 发现（占位，当前点击跳回看板）
- 底部：用户头像 / 当前空间信息

### 1.3 命令面板（⌘K）
- 搜索
- 交易（s）
- AI 助手（a）
- 快捷操作：
  - 新建流水（t）
  - 新建账户（a）
  - 新建分类（c）
- 打开目录：账户、目标、预算、交易、发现
- 操作：设置（s）、帮助、Twitter

### 1.4 全局设置
设置以抽屉/全页面形式呈现，左侧为菜单：

**通用配置**
- 用户信息：邮箱、修改密码、用户 ID、退出其他客户端、删除账号
- 个性偏好：主题（浅色/暗黑）、语言、快捷键、默认登录页、菜单显隐（看板/预算/目标/报表/发现）
- 数据安全
- AI 配置：模型列表、新建模型、名称/模型/地址

**当前空间**
- 空间配置
- 账单导入
- 分组分类
- 交易规则
- 标签
- 商户

**产品信息**
- 会员
- 分享
- 关于

## 二、看板（Dashboard /home）

### 2.1 欢迎区
- 用户昵称 + 问候语
- 当前日期、星期、天气图标

### 2.2 资产概览（三卡片）
- 净资产：金额 + 涨跌幅
- 收入：金额 + 涨跌幅
- 支出：金额 + 涨跌幅

### 2.3 资产趋势
- 折线图/面积图（双图并列）

### 2.4 资产分布
- Tab 切换：按账户 / 按交易方式
- 饼图/环形图
- 空状态：暂无数据

### 2.5 收支日历
- 日历视图
- 空状态：暂无数据

### 2.6 右侧边栏
- 还款提醒（暂无待还款）

- 最近交易：快捷添加首个交易

## 三、账户管理（/account/list）

### 3.1 空状态
- 标题：创建账户
- 描述：账户用于管理资产和交易，例如银行账户、支付宝、微信、投资、社保、不动产等
- 操作：新建账户

### 3.2 新建账户流程
**第一步：选择账户类型**
- 资产类：
  - 资金（日常收入和支出账户：银行储蓄卡、微信、支付宝、现金等）
  - 资产（保值或增值账户：定期存款、购房储蓄等）
  - 社保（社保、公积金、医疗保险）
  - 投资（股票、基金、数字货币等）
  - 其他（收藏品、艺术品、非常规资产）
- 负债类：
  - 信用（信用卡、花呗、京东白条等）
  - 债务（车贷、房贷、信用消费贷款等）

**第二步：填写账户信息**
- 账户名称（必填，0/20 字）
- 账户余额（¥）
- 备注（0/200 字）
- 标签（下拉搜索）
- 计入资产（开关）
- 确认

### 3.3 账户列表（推测）
- 账户卡片/列表展示
- 支持点击跳转 `/account/detail/:id`

---

## 四、交易流水（/transaction）

### 4.1 空状态
- 标题：创建流水
- 描述：流水记录每一笔收支，包括工资收入、日常消费、转账、投资理财等
- 操作：新建流水、批量导入

### 4.2 新建流水表单
- 类型切换（Tab）：支出 / 收入 / 转账 / 不计收支
- 名称/描述输入（如：购物，餐饮等支出）
- 交易日期（日期时间选择器）
- 金额（¥）
- 分类（下拉）
- 账户（下拉搜索）
- 备注（0/200 字）
- 标签（下拉搜索）
- 商户（下拉搜索）
- 计入资产（开关）
- 确认

### 4.3 批量导入
- 支持 CSV / PDF 格式，最大 10MB
- 支持拖拽上传
- 支持平台选择：支付宝、微信、广发银行、招商银行、恒丰银行、华夏银行、平安银行、浦发银行、民生银行、兴业银行、交通银行、工商银行、农业银行、邮储银行、中信银行、四川农信银行等
- 解析账单按钮
- 历史记录 Tab

## 五、目标管理（/goal/list）

### 5.1 空状态
- 标题：创建目标
- 描述：目标助你实现财务梦想，例如购房首付、应急基金、旅行储蓄、教育基金等

### 5.2 新建目标流程
**第一步：选择目标类型**
- 存款目标：买房、买车、应急基金、教育、旅游、存钱、养老金、其他
- 还款目标：信用卡、助学贷款、汽车贷款、房贷、其他

**第二步：填写目标详情**（未进一步展开，推测包含）
- 目标名称
- 目标金额
- 当前已存金额
- 截止日期
- 关联账户
- 图标/颜色

## 十、AI 功能（可本地降级实现）

### 10.1 原产品实现
- 调用智谱 GLM API：`https://open.bigmodel.cn/api/paas/v4/chat/completions`
- 模型：glm-4-plus
- 支持自然语言查询财务数据

### 10.2 本地复刻替代方案
- 可选接入本地 Ollama / LM Studio 模型
- 或接入用户自有 OpenAI / 智谱 API Key
- 默认关闭，由用户手动配置

## 十二、本地复刻建议的 MVP 范围

如果只做"壳子 + 本地功能"，建议优先实现：

1. **看板 Dashboard**（首页，展示资产概览和空状态图表）
2. **账户管理**（创建、列表、详情）
3. **交易流水**（创建、列表、筛选）
4. **目标管理**（创建、列表、进度）
5. **分类/标签/商户**（本地 CRUD，预设默认值）
6. **账单导入**（CSV 解析，本地处理）
7. **基础设置**（主题、语言、默认页、菜单显隐）
8. **命令面板 ⌘K**（页面跳转和快捷操作）

可以后置或不做的：
- 云端同步/登录注册
- AI 助手（可做成可配置插件）
- 预算/发现（当前原站也是占位）
- 会员/分享/多设备管理
